# sparthon4_solved-lv3-

브라우저에서 버킷리스트 항목을 추가하고 완료 표시·로컬 저장을 실험한 HTML·JavaScript 작업물입니다. 화면에는 **SPARTHON Bucket List**라는 제목이 있으며 두 가지 페이지 버전이 들어 있습니다.

## 파일과 열어 보기

| 파일 | 내용 |
|---|---|
| [index.html](index.html) · [script.js](script.js) | 텍스트와 이미지 번호를 입력하는 버전 |
| [index2.html](index2.html) · [script2.js](script2.js) | 이미지 번호를 선택 목록으로 고르는 버전 |
| [assets](assets/) | 배경·카드 이미지와 스타일 |

`index.html` 또는 `index2.html`을 브라우저에서 엽니다. 항목 추가 폼과 카드 클릭에 연결된 코드를 확인할 수 있습니다.

## 기록 범위

- DOM 요소 생성과 클릭 이벤트 처리
- `localStorage`의 `bucketItems`를 이용한 항목 저장·복원 시도
- 완료 상태 변경과 삭제 기능을 다루는 실험 코드

완료 상태 저장·삭제 코드는 완성된 기능으로 보증하지 않으며, 코드 비교와 학습 기록을 위한 자료입니다. 과제의 정확한 과정·원본 출처는 현재 저장소 문서에 기록되어 있지 않습니다.
